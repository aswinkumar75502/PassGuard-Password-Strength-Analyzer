Why password
security matters

In a world of persistent digital threats, your password is often the only barrier between attackers and your sensitive data. PassGuard helps you understand and improve your defences — instantly, privately.

🚨

The Scale of the Problem

Over 23 billion credential pairs were exposed in data breaches in 2023 alone. Credential stuffing, brute-force attacks, and dictionary attacks are fully automated and can test millions of passwords per second against stolen hashes. A weak 6-character password can be cracked in under a second with modern GPUs.

🔬

How PassGuard Analyzes Your Password

PassGuard evaluates five core criteria — length, uppercase, lowercase, numbers, and special characters — and assigns a weighted score from 0–100%. The analysis runs entirely in your browser. Your password is never transmitted, logged, or stored anywhere. We use the window.crypto API for secure random generation, not Math.random().

🛡️

What Makes a Password "Excellent"?

NIST SP 800-63B (2023) recommends at least 15 characters, mixing character classes, and avoiding dictionary words or predictable substitutions (like p@ssw0rd). PassGuard awards full marks for passwords that satisfy all five rules and exceed 16 characters — matching industry best practice.

🏗️

Tech Stack

Frontend: Pure HTML5, CSS3 (glassmorphism, CSS custom properties, keyframe animations), and Vanilla JavaScript — no frameworks, no dependencies.

Backend (optional): Python Flask REST API for server-side scoring and demo logging. Run with python app.py after installing requirements.

Fonts: Syne (display), DM Mono, DM Sans — all via Google Fonts.

⚖️

Privacy Commitment

PassGuard operates on a strict zero-knowledge principle for the frontend. No analytics SDK, no telemetry, no third-party scripts that could intercept keystrokes. The optional backend stores only an anonymised strength score and timestamp — never the password itself — and is disabled by default.
