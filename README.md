# 🔐 PassGuard – Password Strength Analyzer

PassGuard is a modern frontend web application that analyzes password strength and helps users generate stronger passwords through a clean, responsive interface.

## ✨ Features

- Real-time password strength analysis
- Password strength score and visual indicator
- Strong password generation
- Show/hide password functionality
- Copy generated passwords
- Clear password input
- Password security tips
- Responsive dark-themed UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `frontend/index.html` in your browser.

Adjust the file path if `index.html` is located in the root directory.

## 🔒 Privacy

Password analysis is intended to run locally in the browser. Review the source code to verify how passwords are processed before making privacy claims.
